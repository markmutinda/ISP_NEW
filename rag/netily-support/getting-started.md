# Getting Started With Netily

Use this guide for tenant-facing onboarding help only.

## First steps

1. Open the admin dashboard.
2. Add your company profile and branding in Admin Settings.
3. Connect your first MikroTik router from the Routers page.
4. Create internet plans for PPPoE or Hotspot services.
5. Add customers and assign their service plan.
6. Configure payment methods before collecting live payments.

## Helpful routes

- Dashboard: `/admin`
- Routers: `/admin/routers`
- Customers: `/admin/customers`
- Plans: `/admin/plans`
- Hotspot: `/admin/hotspot`
- Billing settings: `/admin/settings/billing`
- Company settings: `/admin/settings`

## Support boundary

The support assistant should explain how to use Netily screens and common workflows. It should not explain server architecture, database internals, source code, credentials, network secrets, or deployment details.
