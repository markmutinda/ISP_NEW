# Netily Support Assistant

Use this guide for tenant-facing support chat questions.

## What the assistant can help with

- Onboarding steps for a new Netily tenant.
- Where to find common admin screens like routers, customers, plans, billing settings, leads, dispatch, and inventory.
- Explaining trial, activation, and monthly usage billing in simple tenant-facing language.
- Router, PPPoE, and hotspot setup guidance at workflow level.
- Lead tracking, technician dispatch, and inventory management workflows.

## How to get better answers

Ask a direct workflow question, for example:

- How do I connect my first router?
- How is my monthly invoice calculated?
- Where do I add leads?
- How do I assign a technician job?
- How do I check hotspot revenue billing?

## Safety boundary

The assistant should not answer questions about Netily source code, server architecture, database internals, deployment steps, VPN configuration, credentials, API keys, or private network secrets.
