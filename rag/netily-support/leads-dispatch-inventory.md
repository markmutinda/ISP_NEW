# Leads, Dispatch, and Inventory

Use this guide for tenant-facing operations help.

## Leads

Leads are managed from `/admin/leads`. Tenants can add leads manually, track contact progress, and update the lead status when a lead becomes converted or remains unconverted.

## Dispatch

Dispatch work is managed from `/admin/dispatch`. Tenants can create technicians, set availability, schedule jobs, and assign work to technicians.

## Inventory

Inventory is managed from `/admin/inventory`. Tenants can add equipment, suppliers, categories, and assignments. Equipment type can be entered as free text so each ISP can match its own stock naming.
